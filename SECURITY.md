# Security Policy

## Reporting a Vulnerability

Please do not report security vulnerabilities through public GitHub issues.

To report a security issue, contact the project maintainer through:

https://oddstyle.ru/

Please include:

- a clear description of the vulnerability;
- steps to reproduce the issue;
- the affected plugin version;
- the WordPress and PHP versions involved;
- any relevant logs or screenshots.

## Supported Versions

Security fixes are considered for the currently maintained version of Advanced Category Excluder.
